# Amazing Assistants Online — Landing Site

Standalone marketing SPA, membership checkout pages, and GoHighLevel paste packs for Amazing Assistants Online.

## Quick start

Open `index.html` or `AAO_Website_hallmark.html` in a browser, or serve the folder:

```bash
npx --yes serve .
```

Then visit the local URL shown in the terminal.

## What's included

- Marketing SPA (`index.html` / `AAO_Website_hallmark.html`)
- `pages/` — membership purchase, thank-you, talent/how shells, GHL snippets
- `assets/`, design tokens, messaging/payments example configs

## Config

Copy the example files and fill in your values:

- `payments-config.example.js` → `payments-config.js`
- `messaging-config.example.js` → `messaging-config.js`

Do not commit live checkout URLs or API keys.

## Membership + GHL

See `pages/ghl-membership/README.md` for paste-ready header, hero, order, footer, and thank-you sections.
